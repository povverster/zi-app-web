the development steps and available backend contracts.

records unresolved legal review gates. The separate
[annual preparation API](../zi-app-api/docs/reports/annual-preparation-drafts.md)

current-source status. Its UI is not implemented. Both annual and one-portfolio
reports remain non-filing-ready; preserve financial strings and unknown values.
